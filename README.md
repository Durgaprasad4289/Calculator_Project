# 🧮 Calculator Web App

A **simple, modern, and responsive Calculator application** built using **HTML, CSS, and JavaScript**.  
This project demonstrates **core JavaScript logic, event handling, and DOM manipulation**.

----

## 🌐 Live Demo
👉 **[Click here to view live demo](https://durgaprasadcodes.github.io/Calculator_Project/)**

----

## ✨ Features

- ➕ Addition  
- ➖ Subtraction  
- ✖️ Multiplication  
- ➗ Division  
- 🔄 Clear / Reset function  
- ⌫ Delete last digit  
- 📱 Fully responsive UI  
- 🎨 Clean & minimal design  

----

## 🛠️ Technologies Used

- **HTML5** – Structure  
- **CSS3** – Styling & layout  
- **JavaScript (ES6)** – Calculation logic & events
